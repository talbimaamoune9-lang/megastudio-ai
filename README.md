# MEGASTUDIO AI

A Windows desktop studio for **AI chat**, a **coding agent**, and **image & video generation**, working with both local engines (Ollama, ComfyUI, LM Studio) and cloud providers.

> Version 1.0 · Windows 10 (1809+) / Windows 11 · x64, x86, ARM64

## Features

- AI chat with local and cloud models
- Coding agent that builds and edits projects on your machine
- Image and video generation (local engines or cloud providers)
- English and Arabic interface
- No account required. No analytics or telemetry.

## Privacy

Your data stays on your device. It is sent to a third party only when you choose a cloud AI provider with your own API key. API keys are stored encrypted with Windows DPAPI.

Read the full policy: **[Privacy Policy](PRIVACY.md)**

## Why the app needs full trust (`runFullTrust`)

MEGASTUDIO AI is a traditional desktop app. It needs full trust to launch local programs you choose (Ollama, ComfyUI, dotnet), read hardware sensors (GPU/CPU usage), and access project folders you select. These actions are not possible inside the UWP sandbox.

## Responsible use

Do not use the app to create illegal content, sexual content involving minors, deceptive or non-consensual depictions of real people, or content that infringes others' rights. AI output may be inaccurate; review it before use.
